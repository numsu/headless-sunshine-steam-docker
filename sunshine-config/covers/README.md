# Bolt × RS cover

`bolt-rs.png` is the approved portrait cover for the Old School RuneScape
Sunshine application. It is bundled in the image; startup requires no image downloads.

The composition was made with OpenAI image generation using these references:

- Bolt logo: https://codeberg.org/Adamcake/Bolt/src/branch/master/icon/256.png
- Official RS favicon: https://www.runescape.com/img/rsp777/os-favicon-32x32.png?1

Design: Bolt above a simple ×, with the small RS mark below, on charcoal.
The favicon was enlarged/reconstructed during generation. The logos belong to
their respective owners; this community cover does not imply endorsement.
